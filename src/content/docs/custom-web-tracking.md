This is where ReleaseRadar gets spicy.

You can track changes on normal web pages.

## Examples

- A blog that posts weekly
- A product page you want to watch for price drops
- A restock page
- A "what's new" page for a game / tool / service

## How it works (conceptually)

You give ReleaseRadar a URL and a few rules for what you care about.

If the page changes in a way that matters, it shows up as **New**.
