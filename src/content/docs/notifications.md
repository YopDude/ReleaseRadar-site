Notifications are optional.

If you want ReleaseRadar to stay "quiet" and just be a dashboard, that's totally fine.

## Common setups

- **Sports:** notify when a game starts (and/or ends)
- **Anime / TV:** notify when an episode becomes available
- **Manga:** notify on new chapters
- **Custom web tracking:** notify when a page changes

## One rule

Only turn on notifications you genuinely want.
If it's not meaningful to you, keep it off.
