## Install

Go to **Downloads**, grab the build for your OS, and run it.

## First run

- Launch ReleaseRadar
- Add a few things you care about
- Pick your notification settings (or leave them off and just use it as a dashboard)

## The mental model

ReleaseRadar is a single place to track updates across different domains.

If something changes, it shows up as **New**.
If it doesn't change, it stays quiet.
